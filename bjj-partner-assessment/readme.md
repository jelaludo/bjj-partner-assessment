# BJJ Training Partner Assessment - Python Flask AppThis is a Python Flask application for visualizing and assessing BJJ training partner qualities. The app allows users to rate training partners on various attributes and visualizes the results using color-coded horizontal bars with connecting dots that reveal broader skill patterns.## Project Structure```bjj-partner-assessment/├── app.py├── templates/│   └── index.html├── README.md└── requirements.txt```## Installation1. Clone or download the project to your local machine2. Create a virtual environment (recommended)3. Install the required dependencies```bash# Create a virtual environmentpython -m venv venv# Activate the virtual environment# On Windows:venv\Scripts\activate# On macOS/Linux:source venv/bin/activate# Install dependenciespip install -r requirements.txt```## Running the Application1. Make sure your virtual environment is activated2. Run the Flask application:```bashpython app.py```3. Open your web browser and navigate to `http://127.0.0.1:5000/`## Features- Visual assessment of BJJ training partner qualities through color-coded horizontal bars- Connected dots create a visual pattern to easily identify trends- Switch between different profiles (self-assessment, training partners)- Generate random scores for demonstration- Reset scores to start fresh- Data persistence through Flask API endpoints## Assessment Categories### Technical Attributes- Controlled Movements- Controlled Submissions- Modular Intensity- Depth of Knowledge- Knowledgeable about injury patterns- Ability to work on specifics/give "looks"### Mindset & Attitude- Controlled Ego- Friendly, playful attitude- R&D mindset- Not overtalking/over-explaining- Communicative about boundaries and injuries- Feedback receptivity- Safety consciousness- Recovery awareness- Ability to identify weaknesses & improvements### Others- Hygiene- Reliability## API EndpointsThe application provides several API endpoints for managing profile data:- `GET /api/profiles` - Get all profiles- `GET /api/profiles/<profile_name>` - Get a specific profile- `POST /api/profiles/<profile_name>` - Update a specific profile## Requirements- Python 3.6+- Flask## LicenseThis project is open source and available for any use.
